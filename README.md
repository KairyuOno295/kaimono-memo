# かいものメモ（買い物・欲しいものリスト）

スマホで毎日使う、家族と共有できる「買い物・欲しいものリスト」の PWA（ホーム画面に追加してアプリのように使えるホームページ）です。

- フロントエンド：HTML / CSS / JavaScript（ビルドなし。ES モジュール）
- バックエンド：Supabase（ログイン・データベース・写真の保存・リアルタイム同期）
- 公開先：GitHub Pages（`.github/workflows/deploy-pages.yml`）
- オフライン：サービスワーカーでアプリを保存し、データは端末の IndexedDB に保存。つながったら自動で同期

はじめて設定するときは **[SETUP.md](SETUP.md)** を見てください。
Supabase を設定していない間は **デモモード**（データはその端末の中だけ）で動きます。

## できること

- 複数のリスト（追加・名前変更・絵文字とテーマカラー・並べ替え・削除）、メールアドレスでの共有（リアルタイム反映）
- 品目：名前・数量・メモ・カテゴリ・写真1枚・お店・価格
- 上の入力欄から名前だけで追加、過去の品目を入力候補に表示、名前からカテゴリを自動で推測
- タップでチェック（チェック済みは下に薄く表示）、チェック済みをまとめて削除、左スワイプで削除（数秒間「元に戻す」）
- カテゴリ（絵文字つき・追加できる）ごとにまとめて表示
- 写真：撮影または写真フォルダから選択 → 長辺 800px の JPEG に縮小してから保存。サムネイルとタップで拡大
- 白と紺・青の落ち着いた見た目（線のアイコン・端末の標準の文字）・ダークモード・片手で押しやすい下側のボタン（2026-11-27 KM-012 で変更）

## ファイルの構成

| 場所 | 内容 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目（色のトークン・ダークモード・アニメーション） |
| `js/app.js` | 起動の処理（デモモード／Supabase の切り替え、ログイン、同期の開始） |
| `js/store.js` | データの中心（端末への保存・送信待ち〔outbox〕・同期・取り直し） |
| `js/backend-supabase.js` | Supabase とのやりとり（送ってよい列だけを送る・失敗の分け方・リアルタイム） |
| `js/backend-local.js` | デモモードの送り先（何もしない） |
| `js/db.js` | IndexedDB の小さな入れ物 |
| `js/categories.js` | 標準のカテゴリと、品目名からの推測 |
| `js/image.js` | 写真の縮小（長辺 800px・JPEG） |
| `js/ui/*.js` | 画面（一覧・リスト・詳細シート・共有・設定・ログイン・スワイプ） |
| `js/ui/icons.js` | リスト・カテゴリの線のアイコン。データには絵文字を保存し、画面に出すときだけ線のアイコンにする（対応のない絵文字はそのまま） |
| `sw.js` | サービスワーカー（オフラインで開くための保存） |
| `manifest.webmanifest`・`icons/` | ホーム画面に追加するための設定とアイコン |
| `config.js` | Supabase の接続情報（いまは空＝デモモード）。`config.example.js` がサンプル |
| `supabase/schema.sql` | テーブル・RLS・写真の保存場所・リアルタイムの設定 |
| `tools/serve.py` | パソコンで試すための仮サーバー（127.0.0.1 だけ） |
| `tools/setup_cloud.py` | Supabase と GitHub Pages の準備・公開を自動で行うスクリプト（SETUP.md の「かんたんな方法」。ご本人が合い鍵を入れて実行する。`--dry-run` で送るファイルの一覧だけ） |
| `tests/` | 自動テスト（架空のデータだけを使う） |

## パソコンで試す

```
& "C:\Program Files\FreeCAD 1.1\bin\python.exe" -I -B -X utf8 tools\serve.py
```
→ `http://localhost:8000/` を開く。URL の後ろに `?demo` を付けると、設定があってもデモモードで動きます。

## テスト

```
& "C:\Program Files\FreeCAD 1.1\bin\python.exe" -I -B -X utf8 tests\run_tests.py
& "C:\Program Files\FreeCAD 1.1\bin\python.exe" -I -B -X utf8 tests\check_style.py
```

- `run_tests.py`：Edge を画面なしで動かして、単体テスト・画面の操作テスト（デモモード）・Supabase の流れのテスト・サービスワーカー・オフライン（仮サーバーを止めて開けるか）を確かめ、画面の写真を撮る。
  結果は `c:\AI_work\_テスト出力\買い物リスト\summary.txt`。外のサイトにはつながない設定で動く（写真のフォントは代わりのフォントになる）
- Supabase の流れのテスト（`e2e-sb.js`）は、にせの Supabase（`sb-config.js`）を使う。仮サーバーが `/__sbtest/` の下のページにだけ、`config.js` の代わりに返す
- `check_style.py`：関数の長さ（50行以内）とネスト（3段まで）を数える
- 本物の Supabase での確認（ログイン・RLS・共有・リアルタイム・写真の保存）は、自動テストでは行っていない。
  SETUP.md のとおりに設定したあと、2つのアカウントで確かめること
- 名前に「_旧N_日付」が付いたファイルは変更前の控え（公開されない）

## 安全のための決まり

- `config.js` に書くのは anon（Publishable）キーだけ。service_role・secret キーは書かない
- データを見られる人は、`supabase/schema.sql` の RLS で「本人と共有メンバー」に限っている。書き換えられる列も限っている（持ち主やリストの付け替えはできない）
- 写真は非公開の保存場所に入れ、ファイル名の先頭（リストの ID）で、そのリストのメンバーだけが見られる
- 画面には Content-Security-Policy（読み込んでよい場所の制限）を設定している。Supabase を独自のドメインで使うときは、`index.html` の `connect-src` に足す
